# 中文徽章固件

仅适用于 ESP32-S3-Touch-AMOLED-1.75C（带 C），32MB Flash、8MB PSRAM。

使用已安装 esptool 的 Python 环境，在本目录运行：

```bash
python -m esptool --chip esp32s3 --port /dev/cu.usbmodem1101 --baud 460800 write_flash @flash_args
```

串口名称按实际连接调整。`flash_args` 使用分段烧录，避免合并镜像中间的填充字节无意覆盖 NVS；分区表及应用会被替换。本版保留原厂 NVS 和存储边界；配置格式若不兼容，仍可能需要重新配网。恢复原设备可使用上一级 `device-backup/` 中的整片备份。

本版使用 Flash 头部姿态库。首次安装或资源变更时，必须将匹配的 `xiaozhi.bin` 和 `generated_assets.bin` 配套烧录；已核实资源 SHA256 相同的纯代码更新可只烧录应用。`flash_args` 已包含资源烧录项：`generated_assets.bin` 写入 `0x11f0000` 的既有 `assets` 分区，原分区边界不变。

BOOT 短按切换徽章与两页拓展桌面。徽章上滑或长按展开，桌面下滑收起，应用右滑或点击“返回”。入口为投喂、属性、对话、名片 / 同行、专注、声律、设置；没有息屏应用。另一颗 PWR 电源键短按可在 400 毫秒内渐暗息屏，再次短按渐亮唤醒，渐变中可反向切换；长按约 4 秒仍为硬件关机。息屏时 BOOT 先唤醒并切换徽章/桌面。

息屏停止角色绘制、触摸、六轴跟随与计步，并结束对话和声律采音；专注、提醒与陪伴计时继续。PWR 唤醒保留普通应用页面，对话返回徽章、声律返回桌面。

先摸摸徽章获得 5 金币，即可用“投喂”买鲜果。摸摸奖励每 5 分钟一次，每日最多 60 金币；行走每 100 步 +5，每日最多 100；陪伴每 10 分钟 +2，每日最多 30；完成 15/25/45 分钟专注分别 +6/+10/+18。鲜果、饼干、热饮分别花费 5/8/6 金币。金币和属性自动保存，普通累计记录最多可能在突然断电时丢失最后一分钟。

属性包含此刻心情、精力、饱腹、最近反应，以及亲密度、陪伴天数、成长等级、共同步数和专注时长。陪伴天数按累计开机时长计算；离线每日额度按开机 24 小时重置，有有效联网时间后按 UTC+8 日期计日。

同行包含今日活动和一起出发；专注支持 15/25/45 分钟、暂停/继续，并附喝水与休息提醒。退出页面继续记录，重启结束未完成计时。名片目前为本地文字二维码，没有关联外部社交账号。

声律显示麦克风真实声音能量变化，退出停止采音。对话使用适配 466×466 圆屏的新布局，返回结束会话并取消待开麦请求。声卡和对话都按需启动；首次使用后的共用音频资源保留，以减少反复初始化，声律不启动语音识别或联网。

主屏保留自然歪头、六轴回正与左右倾倒、呼吸、摆动和眨眼。点按开心，连续点按害羞；六轴本身不触发表情。计步属于基于佩戴动作的估计，需根据实际佩戴位置观察效果。

构建及验证说明见 `../main/boards/waveshare/esp32-s3-touch-amoled-1.75/README.md`。本版原生桌面不再打包旧背景和图标，资源变更时应用及资源须配套更新。
