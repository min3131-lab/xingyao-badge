# 星璃角色资源

使用内置 imagegen 生成的原创粉紫色角色。所有素材按相同构图制作，通过 1.2 倍中心裁切转换到原生 466×466 圆屏坐标；PNG 仅用于素材制作，不在设备上实时解码。

当前角色由独立头部、身体和面部表情构成。动作通过 LVGL 连续几何插值实现，身体和头部可分别呼吸、摆动，面部表情以局部透明度过渡；这不是 Live2D，头发目前随头部整体运动，不包含独立发丝物理。

| 资源 | 裁切矩形 `(x,y,w,h)` | 格式 | 像素字节数 |
| --- | --- | --- | --- |
| 透明头部 | `(0,0,466,350)` | RGB565A8 | 489,300 |
| 身体 | `(0,292,466,174)` | RGB565 | 210,632 |
| 眨眼面部 | `(120,138,216,162)` | RGB565 | 69,984 |
| 开心面部 | `(120,138,216,162)` | RGB565 | 69,984 |
| 害羞面部 | `(120,138,216,162)` | RGB565 | 69,984 |
| 合计 | — | — | 909,884 |

RGB565A8 按 LVGL 布局保存：先完整小端 RGB565 平面，再完整 A8 平面。头部透明度范围为 0–255，保留源素材的透明边缘。表情只存储面部矩形，避免重复存储整张角色。旧整幅主图／眨眼的源码和 PNG 保留，当前界面不引用其整幅 C 资源。

转换入口（在项目根目录运行，需要 Pillow）：

```bash
python scripts/convert_badge_portrait.py badge-assets/星璃-原图.png main/boards/waveshare/esp32-s3-touch-amoled-1.75/anime_badge_portrait.c
python scripts/build_badge_expressions.py
python scripts/build_badge_layers.py
```
